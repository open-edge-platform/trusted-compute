# Samples
1. The [Standalone TC](standalone_tc) includes a collection of sample applications that illustrate how to enable communication with workloads from outside the edge cluster, with only the Trusted Compute application deployed.
2. The [TC with VM](tc_with_vm) comprises a set of sample applications demonstrating how to facilitate communication with workloads from outside the edge cluster, utilizing both the Trusted Compute application and the Virtual Machine application.
